# Dona CRM

Локальная мини-CRM для магазина одежды и аксессуаров: каталог, варианты, остатки и экономика закупок с 1688.

## Запуск

```powershell
dotnet run --project src/Dona.Crm.Web
```

Откройте адрес, который появится в консоли. При первом запуске показываются демонстрационные товары. После первого сохранения данные находятся в `src/Dona.Crm.Web/data/catalog.json`.

## Текущий MVP

- дашборд каталога;
- поиск и фильтрация товаров;
- создание и редактирование карточки;
- варианты по цвету и размеру;
- расчёт себестоимости, прибыли и наценки;
- поставщики и редактируемые категории;
- отдельный справочник посредников по доставке из Китая;
- закупки с позициями, статусами, комиссией и доставкой;
- распределение расходов по весу, учёт MOQ, брака и недостачи;
- оприходование принятого товара в варианты складских остатков;
- клиенты и продажи с позициями заказа;
- резервирование, списание, отмена и возврат товара на склад;
- выручка и прибыль по завершённым продажам;
- коллекции товаров и готовые образы с общей стоимостью;
- контент-план Instagram со статусами и датами публикаций;
- аналитика продаж по периодам, товарам, категориям и клиентам;
- настраиваемые правила низкого и нулевого остатка;
- автоматическое обновление складских статусов и предупреждения по срокам;
- строгая проверка доступного остатка и переходов статусов продажи;
- обратимый архив неактуальных товаров без потери истории;
- autocomplete товаров с поиском по SKU и названию;
- фильтры на всех рабочих списках: поиск, статусы и контекстные параметры раздела;
- сгруппированная навигация по каталогу, закупкам, продажам и маркетингу;
- журнал складских движений для приходов, резервов, продаж, отмен и возвратов;
- отложенный индикатор для длительных операций без мерцания на быстрых переходах;
- удаление товаров с подтверждением;
- глобальная индикация загрузки и операций Google Sheets;
- локальное атомарное JSON-хранилище за интерфейсом `ICatalogRepository`.

Google credentials нельзя добавлять в Git. Подключение Google Sheets описано в [PLAN.md](PLAN.md).

## Подключение Google Sheets

1. Откройте в приложении страницу **Настройки** — там есть официальные ссылки на Google Cloud и создание таблицы.
2. Создайте сервисный аккаунт, включите Google Sheets API и скачайте JSON-ключ.
3. Создайте Google-таблицу и выдайте `client_email` из ключа права редактора.
4. В приложении вставьте ссылку на таблицу и загрузите либо вставьте JSON-ключ.
5. Нажмите **Сохранить настройки**, затем **Проверить** и **Импортировать каталог**.
6. Включите переключатель **Использовать Google Sheets как основное хранилище** и сохраните настройки.

Адаптер автоматически создаёт листы каталога, справочников, закупок, клиентов, продаж, складских движений и контент-плана. Настройки сохраняются в `data/google-sheets-settings.json`, ключ — в `credentials/google-service-account.json`; оба пути исключены из Git.
